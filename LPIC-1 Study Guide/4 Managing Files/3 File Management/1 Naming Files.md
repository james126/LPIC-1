## Naming Files

File names are case sensitive <br>
It's recommend to restrict symbols to **dot(.)** **dash(-)** and **underscore (_)** <br>

> **Dot Files** <br>
> * Filenames can begin with a dot <br>
> * These files are hidden from view by most utilities <br>
> * They are mostly used for storing config files in home directory <br>

A filename that's a **single dot (.)** refers to the current directory <br>
A filename that's a **double dot (..)** refers to parent directory
