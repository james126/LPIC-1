### ls

> `ls [options] [files]` &nbsp;&nbsp;&nbsp;&nbsp; *options/files are optional* <br>
> list files in directory
> ![](../../Image/ls.png

> `ls -l` <br>
> long listing <br>
> show permissions, ownership, file size, creation date, file name <br>
> ![](../../Image/ls-l.png)

> `ls -a` <br>
> show hidden <br>

> `ls -F` <br>
> show file type <br>
> `/` &nbsp;&nbsp; directory <br>
> `.` &nbsp;&nbsp; executable <br>
> `|` &nbsp;&nbsp; named pipe <br>
> `=` &nbsp;&nbsp; socket <br>
> `@` &nbsp;&nbsp; symbolic link <br>
> ![](../../Image/ls-f.png)

> `ls -R` <br>
> recursive <br>
> display current directory and all of its subdirectories <br>
