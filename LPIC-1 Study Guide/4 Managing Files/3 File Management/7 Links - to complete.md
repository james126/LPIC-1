### Links
Like shortcuts in Windows <br> 
<br>

### Hard links
* Two directories that point to the same file <br>
* To delete the file, you must delete both links to the file <br>
* The links must be on the same filesystem to the file <br>

### Soft links (symbolic links)
* A file that points to the linked-to file <br>
* Can point from root (/) filesystem to another filesystem
