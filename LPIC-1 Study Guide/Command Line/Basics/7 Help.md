> ```man``` <br>
> >Short for manual <br>
> Provides summaries of what a command, file or feature does <br>
> Type man followed by command <br>
> ```man pwd``` <br>

<br>  

> ### Less Pager 
>The man utility uses less pager by default to display info <br>
> Displays text one page at a time <br>
> 
> |                  |                       |
> |------------------|-----------------------|
> | ```spacebar```   | move forward one page |
> | ```Esc then V``` | move back one page\   |
> | arrow keys       | Move up/down one line |
> | ```/```          | Search for text       |
> | ```Q```          | quit                  |

<br>

> ```Info``` <br>
>  Shows the textinfo page in a different format <br>
> ```info pwd```

<br>

> ```help``` <br>
> Short description <br>
> Displays info about builtin commands <br>
> ```help pwd```
