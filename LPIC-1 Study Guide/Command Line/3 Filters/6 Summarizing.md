> ```cut``` <br>
> Takes segments of a file and sends to STDOUT
>
> | Options |                                                                                             |
> |---|---------------------------------------------------------------------------------------------|
> | Byte | ```-b list``` <br> ```--bytes=list``` <br> Cuts the specified list of bytes from input file |
> | Character | ```-c list``` <br> ```--characters=list``` |
> | Field | ```-f list``` <br> ```--fields=list``` <br> Cuts the specified list of fields from the input file |
>
> ### List option <br>
> You can make this specification by a number <br>
> Single number e.g.4 <br>
> Closed range of numbers e.g. 2-4 <br>
> Open range of numbers e.g. 4- 

<br>
