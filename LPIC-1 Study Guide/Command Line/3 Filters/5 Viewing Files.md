> ```head``` <br>
> View the start of a file
>
> | Options |                                                              |
> |---------|--------------------------------------------------------------|
> | Bytes | ```-c``` <br> ```--bytes=num``` <br> Display first num bytes |
> | Line | ```-n``` <br> ```--lines=num```                              |

<br>

> ```tail``` <br>
> View the end of a file  
> Example combining head with tail  
> ```Head –n 15 sample.txt | tail –n 5```

<br>

> ```less``` <br>
> Read a file a screen at a time
>
> |         |   |
> |---------|---|
> | ```spacebar``` |Move forward one screen at a time|
> | ```Esc``` then ```V``` |Move backward|
> | ```Arrow keys``` |Move up/down one line at a time|
> | ```/something``` |Search for 'something'|
> | ```Q``` |quit|
