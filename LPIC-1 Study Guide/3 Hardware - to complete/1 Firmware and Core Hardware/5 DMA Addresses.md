### Directory Memory Addressing
* Alternative method of communication to I/O ports <br>
* Instead of having CPU transfer data between a device and memory, DMA allows transfer directly between device and memory bypassing the CPU<br>
* The *x86* architecture uses several DMA channels, each can be used for a device <br>
