### Process CPU Usage
> ```top```
>  
> |                | options                                                                                                          |
> |----------------|------------------------------------------------------------------------------------------------------------------|
> | ```-d delay``` | wait delay seconds between updates                                                                               |
> | ```-p pid```   | can specify up to 20 Process IDs                                                                                 |
> | ```-n iter```  | display a certain number of updates (iter) then quit. usually it keeps updating until you terminate the program. |

> Commands you can enter while ```top``` is running
> 
> |   |                                                                               |
> |---|-------------------------------------------------------------------------------|
> | k | kill a process, it will ask for the PID                                       |
> | q | quit                                                                          |
> | r | change process priority, it will ask for PID and value to increment/decrement |
> | P | sort by CPU usage (default)                                                   |
> | M | sort by memory usage                                                |
