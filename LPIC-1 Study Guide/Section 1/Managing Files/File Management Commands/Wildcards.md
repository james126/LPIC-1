# Wildcards

A symbol that stands for other characters

> Question mark **?**
> single character
> `b??k` → book etc

> Asterisk **\***
> any characters, including no character
> `b*k` → bk, book

> Brackets **[]**
> any character is the set
> `b[ae]ok` → baok
> `b[ae]o[kds]` → baok

> Range of values **[-]**
> `b[a-z]ck` → back
