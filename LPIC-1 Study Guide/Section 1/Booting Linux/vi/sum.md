# vi/vim
**vi** visual editor
**vim** vim improved
<hr>

# vi modes
At any moment, vi is running 1 of 3 modes:
<span>&nbsp;</span>

1. **Command Mode** 
normal mode
accepts commands
<span>&nbsp;</span>

2. **Ex Mode**
for more complex commands
often for saving, quitting
type <b>:</b>
<span>&nbsp;</span>

3. **Insert Mode**
edit mode
inserting text
<span>&nbsp;</span>

`Esc` returns you to command mode
<hr>

# Using vi
*example*
* open file `vi cooking.txt`
* include file extension
* the tildes (~) down the left side indicate end of file
* the bottom line shows status of the last command

commands
|||
|-|-|
| `u` | Undo |
| `/someText` | search forward |
| `?someText` | search backward |
| `:w` | save |
| `:q` | quit |
