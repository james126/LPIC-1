# Using vi

example

open file
`vi cooking.txt`
include file extension
the tildes (~) down the left side indicate end of file
the bottom line shows status of the last command

commands
|||
|-|-|
| `u` | Undo |
| `/someText` | search forward |
| `?someText` | search backward |
| `:w` | save |
| `:q` | quit |
