### Exam Essentials
* *Using the shell* <br>
``history`` command history <br>
``tab`` auto complete <br>
`↑` previous command <br>
<br>

* ```man``` <br>
manual for a keyword <br>
<br>

* ```env``` <br>
environment variables <br>
<br>

* _Standard output_: normal output of program <br>
_Standard error_: high-priority output e.g. error messages <br>
<br>

* *Pipes* <br>
feed standard input from first program into second programs standard input <br>
<br>

* *Filter commands* <br>
manipulate text e.g. combining files <br>
<br>

* *Regular Expressions* <br>
```grep```
