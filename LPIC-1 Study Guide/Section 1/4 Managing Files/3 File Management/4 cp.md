### cp

> `cp [options] source [destination]` &nbsp;&nbsp;&nbsp;&nbsp; *source can be multiple files* <br>
> `cp old-file new-file` <br>
> copies a file

![](../../Image/cp1.png)

The destination may be a directory <br>
![](../../Image/cp2.png) <br>

| option |                                                                                                              |
|--------|--------------------------------------------------------------------------------------------------------------|
| -f     | force <br> overwrite files without prompting                                                                 |
| -i     | interactive <br> ask before overwriting files                                                                |
| -R     | recursive <br> if you specify the source as a directory, the directory and all its subdirectories are copied |
| -u     | update only if source is newer than target or target doesn't exist                                           |
                                                                                                          |
