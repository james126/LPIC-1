# Yum 

alternative to `rpm`
automatically locates packages by searching its repositiries

> `yum [options] [command] [package]`
> 
> | command          |                            |
> |------------------|----------------------------|
> | `install`        |                            |
> | `update`         | update or                  |
> | `check-update`   | check if updates available |
> | `remove` `erase` | uninstall                  |
> | `list`           | display package info       |

options available depend on the command
