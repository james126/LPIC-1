### Exam Essentials
* *RPM packages* <br>
    * `rpm` if you have a RMP package to install <br>
  * `yum` if you need to download the package and then install it <br>
  <br>

* *Debian packages* <br>
  * `dpkg` can install packages locally <br>
  * `apt` gets package from the internet before installing <br>
  <br>

* *Libraries* <br>
  * Shared libraries are code used by different programs <br>
  * Path for shared libraries is `/etc/ld.so.conf`, then type `ldconfig` to reload the shared library memory cache <br>
  <br>

* *Foreground/Background processes* <br>
  * Foreground processes use the terminal <br>
  * Background processes don't use the terminal but are still running <br>
  <br>

* *Processes* <br>
  * You can set a programs CPU priority <br>
  * You can kill a process
