#### Yum 
Alternative to ```rpm``` <br>
Automatic update and installer/removes packages for RPM systems <br>
It automatically searches for packages from repositories <br>
<br>
> Syntax <br>
> ```yum [options] [command] [package...]``` <br>
> 
> | command                     |                                        |
> |-----------------------------|----------------------------------------|
> | ```install```               | install packages and dependencies      |
> | ```update```                | update package or install if not found |
> | ```check-update```          | check if updates available             |
> | ```remove``` or ```erase``` | deletes package                        |
> | ```list```                  | display package info                   |
> | ```search```                | search package names, descriptions etc |
> | ```deplist```               | display package dependencies           |
>
