### RPM
RedHat Package Manager


> #### Package Naming Convention
> ```packagename-a.b.c-x.arch.rpm``` <br>
> 
> |               |                                                                               |
> |---------------|-------------------------------------------------------------------------------|
> | *packagename* | name of package                                                               |
> | *a.b.c*       | version number                                                                |
> | *x*           | build number/release number                                                   |
> | *arch*        | code for package architecture <br> eg i386 for any x86 CPU from 80386 onwards |
