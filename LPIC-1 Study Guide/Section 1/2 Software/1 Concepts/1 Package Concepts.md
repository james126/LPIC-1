### Libraries
Software components that can be used by many different programs

### Package Management
* Relates to programs as files on your hard disk <br>
* Linux provides tools to help you manage running programs (processes) <br>
* You can learn what processes are running, and terminate them <br>

Two main package management tool exist:
* RPM (Red Hat based) and DEB (Debian based)

<br>

> ```.tar``` <br>
> Stands for tape archive <br>
> File format used to bundle directories and files <br>
> ```tar something.tar file1 file2 dir1```
> 
> ### tarball
> A compressed tar file (similar to a zip file) <br>
> ```.tar.gz``` or ```.tgz```

<br>

#### Packages
Usually distributed as single files similar to tarballs <br>
Once installed, consist of many files <br>
Package system tracks them all <br>

<br>

#### Installed File Database
Database of installed files <br>
Includes information about evey file installed via the package system <br>
Name of package, which each of the files belongs to etc

<br>

#### Dependencies
Information about packages and the packages they depend on <br>

<br>

#### Updates
By tracking files and dependencies, package systems allow easy upgrades and uninstallations
