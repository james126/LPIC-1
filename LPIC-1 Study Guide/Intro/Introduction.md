# What is Linux?
- Linux is a clone of Unix operating system
- Unix is paid software
<br>

**Shell**
- a program that accepts and interprets commands 
- provides an interface to the system
- the shell is configured for each invidual user
<br>


**Kernel**
- Hardware control software
- Libraries/utilities that let  users interact with hardware
- Manages resources - CPU, memory, storage, I/O devices
<br>
 
**Distro** 
- Linux OS is available in many different distributions
- They are collections of a specific kernel with different support programs
